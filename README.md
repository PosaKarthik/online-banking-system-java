# Online Banking System

A console-based banking application developed using Java, JDBC, MySQL, and Maven. The project allows users to create bank accounts, deposit and withdraw money, check account balances, and view transaction history. It follows a layered architecture (Model, DAO, Service) and demonstrates Core Java, JDBC, SQL, OOP concepts, and exception handling.

## Technologies Used
- Java
- JDBC
- MySQL
- Maven
- Git & GitHub

## Features
- Create Customer & Bank Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- View Transaction History
- Exception Handling
- Layered Architecture
- Menu Driven Console Application
